# Локальный пул внешности персонажей

Источник: `backend/character_appearance.py`. В игре DeepSeek выбирает ID из пула, а русское описание собирается локально. Дополнительных запросов нет.

| Признак | Варианты |
|---|---|
| Пол (`gender`) | женщина, мужчина |
| Рост (`height`) | низкий, средний, высокий |
| Телосложение (`build`) | стройное, обычное, коренастое, полное, широкоплечее |
| Оттенок кожи (`skin`) | очень светлая, светлая, смуглая, коричневая, тёмно-коричневая |
| Форма лица (`face`) | овальное, круглое, угловатое, вытянутое |
| Цвет глаз (`eyes`) | карие, ореховые, серые, голубые, зелёные |
| Цвет волос (`hair_color`) | чёрные, тёмно-каштановые, каштановые, русые, светлые, рыжие, седые, белые, не применим — без волос |
| Причёска (`hair`) | очень короткие, короткие, каре, до плеч, длинные, хвост, пучок, без волос |
| Растительность на лице (`facial_hair`) | нет, щетина, усы, короткая борода |
| Особая примета (`detail`) | нет, веснушки, родинка, небольшой шрам, простые очки |
| Одежда (`outfit`) | повседневная одежда, пальто, рабочая одежда, дорожный костюм, медицинский халат, строгий костюм, простое платье, служебная форма, длинное одеяние, фантастический комбинезон |
| Основной цвет одежды (`palette`) | серый, коричневый, тёмно-синий, оливковый, бордовый, бежевый |

## Веса различий

Это стартовая эвристика, а не измеренные оценки восприятия. Вес задаёт максимальный вклад признака в расстояние.

| Признак | Вес |
|---|---:|
| Одежда | 5 |
| Пол | 4 |
| Телосложение | 4 |
| Причёска | 4 |
| Возрастная группа | 3 |
| Оттенок кожи | 2 |
| Растительность на лице | 2 |
| Рост | 1.5 |
| Цвет волос | 1.5 |
| Основной цвет одежды | 1 |
| Форма лица | 0.75 |
| Особая примета | 0.5 |
| Цвет глаз | 0.25 |

Пол и одежда фиксированы внутри профиля: их разнообразие обеспечивают квоты профилей. Внутри профиля эти два веса не меняют отбор. Для возраста соседние группы дают половину веса, крайние — полный. Для роста/кожи вклад пропорционален расстоянию между градациями; близкие цвета волос дают 20%, близкие стрижки — 25% веса. Цвет волос не учитывается, если один из образов без волос.


Возраст — отдельное число: в игре 18+, в Colab сейчас 25–60. Это не случайная замена возраста сюжета.

Одежда выбирается целым готовым костюмом. Рабочая одежда и простое платье универсальны; дорожный костюм и длинное одеяние подходят историческим/фэнтезийным мирам, комбинезон — научной фантастике. Остальные профили рассчитаны на современность.

Colab по умолчанию создаёт 240 образов: 2 пола × 10 костюмов × 12. `INCLUDE_EXTRA_OUTFITS=False` оставляет 144 базовых образа. Это не полный перебор 12 групп. `COPIES_PER_PROFILE=4` даёт первые 80 образов со всей одеждой или 48 с базовой; расширение до 12 сохраняет прежние задания.

На профиль пол/костюм создаются 384 воспроизводимых кандидата. Каждый следующий выбирается по максимальному расстоянию до ближайшего уже выбранного в этом профиле (maximin). Основной вклад дают возрастная группа, телосложение и причёска; мелкие детали весят меньше. 12 образов содержат по четыре возраста из групп 25–34, 35–49, 50–60. Веса и бюджет кандидатов находятся в DIVERSITY_RECIPE.

Колаб создаёт обычные взрослые образы: особая примета не обязательна; для женщин в этой выборке растительность на лице не назначается, седые/белые волосы предлагаются с 45 лет. Это правила выборки рисунков, они не переписывают заданные особенности сюжетного каста. Для bald цвет волос — none и не описывается.

Расстояние описаний — эвристика, а не измерение сходства готовых картинок. Текущий банк содержит 235 отобранных спрайтов с разметкой лиц. Назначение учитывает крупные группы, подробные признаки задания не объявлены проверенными на каждом рисунке.

ID сохраняются в `appearance_features`; поле `appearance` остаётся читаемой строкой. Старые свободные описания в сохранениях/JSONL не меняются. Пропущенные или неверные ID нового ответа дополняются локально без повторного запроса.

После изменения пула выполните `python backend/sync_character_appearance.py`: обновятся этот справочник и автономная копия в Colab. Проверка: `python backend/sync_character_appearance.py --check`.
