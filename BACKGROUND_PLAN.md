# План фонов Story Engine

Стиль: цифровая гуашь — простая рисованная иллюстрация, крупные цветовые пятна, мягкая фактура и умеренная детализация.

Основной набор: **80 локаций**. Из них **50 универсальных**, **24 с узнаваемыми особенностями обстановки** и **6 специфических**. Для каждой хранится один базовый фон. Открытые места и помещения с дневным светом получают алгоритмические утро / день / вечер / ночь; закрытые места с постоянным светом не меняются по времени суток. Ещё 6 локаций оставлены в резерве и в этот объём не входят.

В игре хранится по одному дневному исходнику на доступную локацию. Утро, вечер и ночь получаются алгоритмически при показе только там, где это применимо, без отдельных файлов. Классификация всех 80 мест и отдельная постоянная заглушка описаны в `assets/backgrounds/LIGHTING.md`. Все 80 локаций и заглушка подключены к каталогу подбора. Места, для которых в игре понадобилась заглушка, доступны через `/visual/missing-backgrounds` и экспорт `/visual/missing-backgrounds/export`.

## Применимость

- Жанр не ограничивает фон. Детектив, хоррор, драма и приключение могут происходить в любой подходящей обстановке.
- Категории ниже помогают планировать рисунки, а не запрещают использование в определённых мирах.
- Универсальный фон подходит нескольким эпохам за счёт нейтральной обстановки. Это не означает, что он подходит любому описанию: например, обычная шахта не заменяет явно показанную автоматизированную космическую шахту.
- Специальный фон выбирается по видимым условиям сцены: тип транспорта, архитектура, оснащение, магия. Крепость может находиться и в современном мире, конюшня — в научно-фантастическом, если это соответствует тексту.
- Нельзя подменять явно описанную технику или материалы несовместимыми. При отсутствии подходящего фона лучше нейтральная композиция или отсутствие изображения, чем случайная картинка другого мира.
- При создании рабочего каталога универсальность должна задаваться через совместимость и признаки обстановки; названия групп в этом документе не превращаются в жёсткие жанровые или мировые фильтры.

## Правила рисования

- Формат 16:9, одна композиция для всех применимых вариантов времени суток. Для постоянного освещения существует только базовый вариант.
- Утро: мягкий тёплый свет. День: нейтральный свет. Ночь: холодный окружающий свет и локальные источники.
- В помещениях без дневного света и космических интерьерах освещение постоянное. Для чужой планеты варианты соответствуют местному циклу освещения.
- Без отдельных версий дождя, грозы, тумана, снега и других погодных состояний. Погода передаётся текстом, динамическими частицами и плавным изменением палитры; локальные правила проверяют применимость к фону.
- Без людей, животных, читаемых надписей, логотипов и важных сюжетных предметов. Они не должны случайно появляться на каждом повторном использовании фона.
- Детали конкретной эпохи добавляются только там, где они определяют локацию. Для универсальных фонов действуют ограничения в таблицах.
- Оставлять спокойные области в нижней части кадра под текст, а в центре и по бокам — под будущие спрайты.

## Резерв

Эти места сохраняют самостоятельную визуальную идентичность, но не входят в стартовые 80 локаций. Их добавление зависит от того, насколько часто они появятся в сюжетах.

| Локация | Когда добавлять |
|---|---|
| Рулевая рубка | Для историй, где важно управление морским судном; требует определения типа судна. |
| Морг | Для медицинских и криминальных сюжетов; отдельное специализированное помещение. |
| Зал суда | Для сюжетов с судебным разбирательством; общий зал собраний не заменяет его при явном описании. |
| Ночной клуб | Для историй с танцполом и клубным освещением. |
| Профессиональная кухня | Для историй о ресторанной работе; отличается от домашней кухни. |
| Платформа метро | Для сцен ожидания подземного городского транспорта. |

## Проверка покрытия на типовых историях

| Ситуация | Подходящие фоны |
|---|---|
| Путешествие на корабле | Причал → подходящая палуба → каюта / трюм → берег. |
| Поездка между городами | Вокзал / аэропорт → поезд / самолёт; либо автомобиль / автобус → заправка → холл → спальня. |
| Детектив в современном городе | Улица → переулок → кабинет → архив → подвал → заброшенное помещение; специальные учреждения добавляются при необходимости. |
| Путешествие в мире с крепостями | Улица поселения → конюшня → повозка → дорога → лагерь → мост → двор крепости. |
| История о ремесле или производстве | Мастерская / кузница / шахта / цех → склад → кабинет → зал собраний. |
| Экспедиция на другую планету | Мостик → коридор станции → ангар → поверхность планеты → лагерь; природные фоны используются, если ландшафт действительно похож на земной. |
| Хоррор в замкнутом пространстве | Коридор → подвал → заброшенное помещение → тоннель / камера / корабельный трюм. |

Текущий подбор опирается прежде всего на текущее место и описанную обстановку. Упоминание корабля в воспоминании или жанр «мрачный» сами по себе не меняют локацию или время суток.
