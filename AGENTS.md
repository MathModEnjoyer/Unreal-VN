# Работа с проектом

- Отвечать пользователю по-русски. Язык существующего кода и комментариев сохранять.
- Перед изменением генерации сюжета, персонажей или графики читать `DECISIONS.md`.
- Считать текущие указания пользователя приоритетными. Не выдавать обсуждавшиеся
  предложения за реализованные решения и не отменять ранее согласованные решения
  без нового указания пользователя.
- После принятого изменения актуализировать статус в `DECISIONS.md`.
- Проверки Python: `python -m unittest discover -s backend/tests -v`.
  Проверки графики/звука: `node --test frontend/src/*.test.js`; сборка: `npm run build`
  из `frontend`. Не расходовать реальные API-токены вместо локальных тестов.

## Проверка сегментов (23 октября 2026)

- По прямому указанию пользователя возвращена одна проверка целого нового
  посещаемого сегмента перед прозой. Прозу отдельно не проверять.
- Thinking отключён во всех запросах DeepSeek, включая меню, каст, план,
  события, прозу и проверки. reasoning_effort не передаётся.
- Модель возвращает replacements (event_index с нуля, path, old, new), Python
  применяет правки атомарно. Не запускать LLM для сопоставления или применения замен.
- Финал проверяется в этом же запросе; разрешена замена целых событий без изменения
  их количества. Проверенный план сохранять до прозы и повторно не оплачивать при её сбое.
- Уточнения игрока передаются в каст. kind=nonhuman всегда использует сферу.
- Структурное событие владеет переходом move/cut; цитата из новой прозы не нужна.

- Проза получает только текущий сегмент событий и справочник персонажей/стиль.
  Не добавлять к ней историю, общий план, канон и скрытые сюжетные цели каста.


## Экономия промптов (23 октября 2026)

- Неизменные правила прозы, формат blocks и запрет повторять метаданные находятся
  в системном префиксе рядом со стабильным справочником. Меняющиеся выбор/финал
  и события — в пользовательской части. В одном запросе правила не дублируются.
- Планирование и проверка сохраняют общий префикс: каст/канон, затем полный
  дополняемый исходный журнал; каталог и динамические задания идут после журнала.
  Проза получает только текущий сегмент и справочник с признаком ГГ.
- Уточняющие вопросы сокращены до рабочих правил; из инструкции общего плана
  убраны объяснения причин самих инструкций. Состав запросов не увеличен.
- Для ключевых действий результат и оставшееся ограничение описываются прямо
  в событии; части предмета различаются. Наблюдение отделяется от версии персонажа.
  Не вводить новые правила мира только ради разрешения конфликта.
- В справочнике планирования явно указаны пол и признак ГГ, даже если описание
  назначенного спрайта обезличено. Постоянство префикса сохраняется при чтении сцен.
- Удалён неиспользуемый _as_bool; исправлено устаревшее описание контекста прозы.
  Чтение старых сохранений и продолжение старых текстовых планов сохранены.
- Совпадение префикса даёт возможность кеширования, не гарантирует попадание.
  Процент экономии в рублях определяется реальными usage/cache_hit/cache_miss;
  локальная проверка длины текста не является измерением токенов или цены.
