# Базовая разметка лиц — 21.10.2026

Размечены все 235 оставленных спрайтов. Изображения не менялись.
Все точки просмотрены поверх лиц, ошибочные положения исправлены.
Это приблизительные управляющие точки для последующей разработки эмоций,
а не плотная сетка лица, точные границы век или готовый анимационный риг.

## Координаты

face_landmarks.json → characters → ID содержит:

- cutout и cutout_sha256: точная привязка к версии PNG; при несовпадении хеша
  разметку необходимо проверить заново, нельзя применять молча к другой картинке.
- size: 640×960. Начало координат в левом верхнем углу, X вправо, Y вниз.
  left/right — слева/справа для зрителя, а не анатомическая сторона персонажа.
- points_px: центры двух глаз, центры двух бровей, левый/средний/правый ориентиры
  рта. Координаты рта — управляющие ориентиры: они не описывают исходную кривизну губ.
- points_normalized: те же точки как x/640, y/960. Для масштабированного спрайта
  умножать на его фактические ширину/высоту и добавлять положение на экране.
- regions_px: рабочие прямоугольники глаз/бровей/рта/лица [x0,y0,x1,y1),
  вычисленные из точек. Не использовать их как точную сегментацию кожи.
- review_flags: очки, усы/борода, поворот головы, волосы у глаза и слабая
  детализация. Это визуальные предостережения для обработки, не сюжетные признаки.
- review_status=visual_anchor_reviewed: проверено положение ориентиров.
  emotion_ready=false: деформации и эмоции ещё не испытаны.
  baseline_expression_verified=false: исходные выражения не объявлены нейтральными.

## Просмотр и воспроизведение

Открыть face_gallery.html обычным браузером. Есть выбор персонажа, стрелки,
показ точек/рабочих областей и полного спрайта; сеть и сервер не нужны.
Для контроля можно сравнивать лицо с включёнными и выключенными точками.

Исходные ориентиры: ../../tools/character_face_anchors.txt.
Инструмент сборки (Python + Pillow):

```text
python tools/build_character_face_landmarks.py assets/characters <отдельный-output.json> --sheets <папка-превью>
```

Инструмент использует визуально заданные ориентиры, проверяет ID/хеши/координаты
и формирует JSON с превью. Это не автоматический детектор новых лиц.
Новый вывод имеет pending_overlay_review: после изменения точек просмотр нужен снова.
Лист проверки исходных 235 изображений хранится в рабочей папке вне игры.
