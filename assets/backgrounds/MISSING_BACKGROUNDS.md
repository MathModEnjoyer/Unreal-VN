# Журнал сцен с заглушкой

После перезапуска сервера игра автоматически записывает сцены, для которых выбран резервный фон. Записи сохраняются между запусками в `%USERPROFILE%\.story_engine\missing_backgrounds.sqlite3`. Файл появляется после первой такой сцены.

В журнал входят локация, текст текущей сцены, жанр, тон, запрошенное время суток, сессия и узел истории, причина выбора заглушки и ближайшие слабые совпадения с каталогом. Накопленная память истории и настройки API в него не входят.

Повторное открытие того же узла той же сессии не добавляет запись. Разные сцены с одним названием места и жанром объединяются в группу; пробелы, регистр и «ё/е» не создают отдельные группы. При отсутствии названия места группировка учитывает текст сцены. Диагностический `/visual/recommend` журнал не пополняет.

При работающем сервере:

- [Скачать список с примерами в Markdown](http://127.0.0.1:8756/visual/missing-backgrounds/export)
- [Скачать полный JSON со всеми сценами](http://127.0.0.1:8756/visual/missing-backgrounds/export?format=json)
- [Посмотреть данные в браузере](http://127.0.0.1:8756/visual/missing-backgrounds)

Группы отсортированы по числу разных сцен. Markdown показывает до трёх примеров каждой группы; JSON содержит все. Если сервер запущен на другом адресе или порту, замените начало ссылки.

По выгрузке можно подготовить следующий список для генерации: проверить, нет ли подходящего существующего фона, объединить близкие названия мест, описать нужные детали и определить освещение. Генерируем дневной оригинал; утро, вечер и ночь обрабатывает игра, а для помещений без естественного света выбираем `fixed`.

Причины `no_matches` и `low_confidence` означают отсутствие уверенного совпадения. `catalog_unavailable` означает сбой каталога: сначала проверьте его загрузку. Ошибка записи самого журнала выводится в лог сервера и не прерывает историю. Журнал отражает выбор резервного фона сервером; ошибки загрузки отдельных изображений в браузере в него не входят.

Для другого места хранения задайте `STORY_ENGINE_MISSING_BACKGROUNDS_PATH` перед запуском сервера. Журнал локальный; автоматической отправки и генерации по нему нет.
