# Освещение фонов

Основных локаций: 80. Открытые: 34; помещения с дневным светом: 30; постоянный свет: 16. Заглушка — отдельно от 80 основных локаций.

Смена времени суток относится к свету на рисунке, а не к жанру или текущим часам истории. Один файл остаётся исходным для всех режимов.

| Категория | Правило |
|---|---|
| `outdoor` | Открытое пространство: алгоритмические утро, день, вечер и ночь. Чужая планета использует местный цикл. |
| `windowed` | Свет приходит через окна, входы или ткань палатки: алгоритмические варианты. Направление нарисованных теней не меняется. |
| `fixed` | Подземное, закрытое или искусственно освещённое пространство: без обработки по времени суток. В API `time_of_day=neutral`. |

У новой повозки крыша и открытые проёмы, поэтому она относится к `windowed`.

Метро классифицировано как `fixed`: наличие окон не означает доступ к солнечному свету. Ангар — `windowed`, поскольку текущий рисунок освещён со стороны открытого входа; для будущего полностью закрытого ангара следует выбрать `fixed`. Космические окна со звёздами не создают земную смену дня и ночи. Аварийный свет, отключение электричества и режим сна не включаются автоматически из-за слова «ночь».

Фоны с дефектами, отмеченные в отдельном визуальном разборе, здесь классифицированы по предполагаемой локации после исправления. Перегенерация картинки не отменяет проверку её режима света.

Поле `time_mode` хранится в `assets/backgrounds/locations.json` и игровом каталоге. При импорте старых наборов политика восстановит обычные категории и исключения метро/ангара. Явно заданное поле имеет приоритет.

## Заглушка: abstract_space

Абстрактная гуашевая подложка в приглушённых серо-синих и серо-бежевых тонах. Без узнаваемой комнаты, предметов, окон, горизонта и направленного дневного света; без утра, вечера и ночи. Применяется, если подбор не дал достаточно убедительного совпадения; в API `is_fallback=true`, `score=0`. Из обычного ранжирования исключена. Поиск по явно указанному текущему месту не подменяется известной локацией из истории.

Картинка сгенерирована и установлена: `originals/abstract_space__day.png` и `backend/backgrounds/abstract_space__day.webp`. Отдельный `StoryEngine_Anima_Fallback_Colab.ipynb` генерирует один PNG 1280×720 без апскейла и временных вариантов в личный Drive, в новый `run_*` с прежним кэшем весов. Основной ноутбук на 80 локаций не изменён.

При следующей замене скопируйте `abstract_space__day.png` и его JSON из нового `run_*/originals` в `assets/backgrounds/originals`, затем из корня проекта выполните:

```bash
python backend/import_backgrounds.py assets/backgrounds
```

Импорт обновит отдельную WebP-заглушку в каталог; 80 обычных дневных PNG останутся источниками основных фонов. Затем перезапустите игру. Суффикс `__day` у заглушки обозначает единственный базовый файл; смена времени к нему не применяется.
