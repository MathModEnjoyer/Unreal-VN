# Музыкальный каталог ccMixter

17 инструментальных композиций: спокойствие, радость, грусть, романтика,
расследование, напряжение, хоррор, экшен. Акустика, оркестр, электроника.
Отбор по описаниям и тегам авторов; это не результат прослушивания всех треков.
Один кандидат с ошибкой декодирования исключён. Остальные полностью декодированы FFmpeg.

Музыка хранится у ccMixter, собственный хостинг и ключ API не нужны.
Публичный API использован при составлении фиксированного каталога:
https://ccmixter.org/query-api. Во время игры скачивается только выбранный
оригинальный MP3 после включения музыки. Генерация сцен и подбор
композиций не ждут сеть и не скачивают музыку.

- music_catalog.json: имена, авторы, теги, настроения, лицензии, фиксированные
  адреса источника, SHA-256/размеры, игровые URL /music/<id>-<hash>.mp3.
- provenance.json: страницы произведений/авторов, сведения о сэмплах,
  длительности, контрольные суммы и результаты проверки на 21.10.2026.
- CREDITS.html: полная атрибуция, доступная из игры по /music-credits.

Все выбранные произведения и указанные на их страницах исходные сэмплы —
CC BY 3.0: https://creativecommons.org/licenses/by/3.0/.
Коммерческое использование допускается при соблюдении условий лицензии.
При распространении сохраните сведения об авторах, сэмплах, источниках и лицензиях.
Оригинальные MP3 не перекодируются и не нормализуются. Громкость регулируется
проигрывателем; полные треки повторяются, бесшовные стыки не гарантируются.

Постоянный кеш: ~/.story_engine/cache/music (на Windows обычно
C:\Users\<имя>\.story_engine\cache\music). STORY_ENGINE_MUSIC_CACHE позволяет
сменить папку. При первом включении нужен интернет. Проверенный кеш работает
после перезапуска без сети. Один файл — примерно 1.5–14 MB; все 17 оригиналов —
примерно 101 MB (97 MiB). Кеш растёт по мере прослушивания. Для очистки
остановите игру и удалите эту папку; файлы загрузятся заново.

Сервер проверяет размер и SHA-256, сохраняет файл атомарно, объединяет
одновременные загрузки одного трека. При сбое скачивания музыка недоступна,
но история продолжает работать; кнопка включения повторяет попытку.
Плеер сохраняет предыдущий трек, пока новый не готов к воспроизведению.
Сервис сторонний: неизменная доступность источников не гарантируется.

Подбор остаётся локальной эвристикой по текущей сцене, жанру и тону —
без дополнительных запросов DeepSeek или локальной нейросети.
В поставку входят каталог и лицензии, аудиофайлы в неё не включаются.
Прежняя локальная библиотека сохранена в резервной копии вне папки игры.
