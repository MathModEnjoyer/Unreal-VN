# Публикация на GitHub

Папка проекта подготовлена как исходный репозиторий. Локальные зависимости,
frontend-бандл и кэши удалены; оригиналы графики, рабочие ассеты и тесты оставлены.
Персональные настройки, ключ и истории вне проекта не удалялись.

## Перед первой загрузкой

1. Прочитайте `LICENSING.md`: код — PolyForm Noncommercial 1.0.0, собственные
   визуальные материалы — CC BY-NC 4.0 в пределах имеющихся прав. Сторонняя музыка
   и библиотеки сохраняют свои условия. Готовые картинки Anima могут использоваться
   коммерчески по лицензии модели; ограничения проекта не следуют из Anima.
2. В GitHub создайте пустой репозиторий. Не выбирайте автоматически MIT/GPL:
   файлы LICENSE, NOTICE и описания областей уже включены.
3. В корне проекта выполните `python tools/check_publication.py`.
   Это локальная эвристическая проверка, не доказательство отсутствия любых секретов.
4. Перед коммитом просмотрите `git status --short`, `git diff --cached --stat`
   и добавленные текстовые файлы. Не добавляйте собственные логи, конфиг, сохранения
   и архивы. При ручной загрузке через сайт GitHub `.gitignore` не фильтрует
   выбранные вами файлы автоматически.

В подготовленной папке Git ещё не инициализирован. Команды первой публикации
(вместо `URL_ВАШЕГО_РЕПОЗИТОРИЯ` вставьте HTTPS/SSH-адрес из GitHub):

```sh
git init
git branch -M main
git add .
git status --short
git diff --cached --stat
git commit -m "Initial release of Story Engine"
git remote add origin URL_ВАШЕГО_РЕПОЗИТОРИЯ
git push -u origin main
```

## Что исключено

`.gitignore` исключает `node_modules`, `.venv`, кэши Python, `dist`, логи,
личные конфиги, базы, модельные веса и архивы. `package-lock.json` оставлен:
для восстановления зависимостей используется `npm --prefix frontend ci`.
После сборки локальный `frontend/dist` снова появится, но в Git не попадёт.
Проверка публикации предупредит о локальных данных; запускать её удобнее
на чистом клоне до установки/сборки либо после локальной очистки.

Полный текущий набор исходников и ассетов — около 109 МБ, отдельные файлы меньше
100 МиБ. Git LFS не требуется, но понадобится пересмотреть это при добавлении
больших архивов, аудио или моделей. Папки оригиналов не удаляйте ради экономии:
они нужны для повторной обработки и не являются установленными библиотеками.

## Личные данные

- Ключ: `~/.story_engine/config.json`, не находится в проекте или сборке.
- Прогресс: `~/.story_engine/sessions`.
- Транскрипты/debug: рабочий стол или выбранная игроком папка; запасной путь —
  `~/.story_engine/saves`.
- HTTP-журнал: `logs/deepseek` рядом с проектом/EXE. Ключ маскируется, сами
  затравки, уточнения и ответы модели остаются личными данными.

Не копируйте `.story_engine` в репозиторий. Если реальный ключ когда-либо оказался
в опубликованном коммите/архиве, отзовите его в DeepSeek: `.gitignore` и удаление
файла не удаляют секрет из старой истории Git или чужих копий.

## Готовая сборка

EXE публикуйте отдельно через GitHub Releases после локальной сборки и проверки.
Приложите LICENSE, NOTICE, LICENSING.md и необходимые лицензии/уведомления
встроенных библиотек. Полный исходный репозиторий и готовый релиз — разные пакеты.
