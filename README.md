# Story Engine

Визуальная новелла, в которой DeepSeek создаёт историю по вашей затравке:
персонажей, события, диалоги и развилки. Фоны и спрайты поставляются с проектом;
время суток, погода, освещение и эмоции обрабатываются локально.

**Для генерации нужен собственный API-ключ DeepSeek и интернет. Запросы платные.**
Полностью написанную историю можно перечитывать без новой генерации.

Проект доступен для некоммерческого использования на условиях
[PolyForm Noncommercial 1.0.0](LICENSE). У графики, музыки и зависимостей
есть отдельные условия — см. [LICENSING.md](LICENSING.md).
Это source-available проект, а не open source по определению OSI.

## Установка из исходников

Нужны Python 3.11+ и Node.js 20.19+ / 22.12+ с npm. Команды выполняются
из корня скачанного репозитория. Git LFS для текущего набора файлов не требуется.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm --prefix frontend ci
npm --prefix frontend run build
.\.venv\Scripts\python.exe backend/run.py
```

Linux/macOS:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm --prefix frontend ci
npm --prefix frontend run build
.venv/bin/python backend/run.py
```

Игра откроется в браузере. Сервер слушает только `127.0.0.1`; обычный порт —
8756, при занятости выбирается свободный. Адрес напечатан в консоли.
Не закрывайте сервер, пока играете. Ключ вводится в настройках игры.

`node_modules` и `frontend/dist` не хранятся в Git: `npm ci` и сборка создают их.
Веса Anima, ComfyUI и GPU для запуска игры не нужны.

## Как играть

- Выберите затравку, жанр, тон и ответьте на уточняющие вопросы.
- Экономичный режим генерирует события продолжения после выбора; обычный
  заранее готовит две ближайшие альтернативы и допускает собственное действие.
- Продолжение: кнопка, Enter, Space или клик по свободной области.
  Выборы и финальные кнопки требуют явного нажатия.
- В шестерёнке — API-ключ, музыка, погодный звук, громкость, размер шрифта
  и журнал недостающей графики. Музыка скачивается по необходимости со стороннего
  сервиса; его доступность не гарантируется.
- Сгенерированный текст может содержать ошибки. Одна проверка сегмента событий
  снижает часть противоречий, но не гарантирует логической безупречности.

## Личные данные и журналы

API-ключ хранится в `~/.story_engine/config.json`, вне исходников и EXE.
В Windows это `%USERPROFILE%\.story_engine\config.json`. На диске ключ хранится
в открытом виде: не передавайте этот файл другим. Чтобы удалить ключ, закройте
игру и удалите `config.json`. Пустое поле в интерфейсе оставляет прежний ключ.

Снимки историй находятся в `~/.story_engine/sessions`. Транскрипты и debug-логи
сохраняются на рабочий стол, если он существует, иначе — в
`~/.story_engine/saves`; игрок также может указать другую папку.

Журналы DeepSeek записываются в `logs/deepseek` рядом с проектом либо EXE.
В них есть запросы, ответы, ошибки, токены и попытки; ключ маскируется.
Сюжетный ввод отправляется DeepSeek для генерации. Музыка загружается с ccMixter.
Интерфейс также запрашивает шрифты из Google Fonts; при недоступности сервиса
используются запасные системные шрифты.
Файлы журналов, персональные настройки и пользовательские истории публиковать
в репозитории не следует. `.gitignore` их исключает, но не очищает историю Git.

## Разработка и проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests -v
npm --prefix frontend test
python tools/check_publication.py
```

На Linux/macOS замените путь к Python на `.venv/bin/python`.
Тесты используют подставные ответы и не расходуют реальные API-токены.
Для разработки интерфейса запустите сервер и отдельно
`npm --prefix frontend run dev`. Vite работает на порту 1420 и проксирует API
на 8756; при таком запуске порт 8756 должен быть свободен.

## Сборка Windows EXE

На Windows, после установки `requirements-build.txt` и сборки интерфейса:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
npm --prefix frontend run build
Set-Location backend
..\.venv\Scripts\python.exe -m PyInstaller --distpath ../dist run.spec
Set-Location ..
.\dist\StoryEngine.exe --check-runtime
```

Результат — `dist/StoryEngine.exe`. Python/Node у игрока не требуются.
EXE не хранится в исходном репозитории; его можно приложить к GitHub Release.
При распространении сборки приложите лицензии проекта и уведомления о фактически
включённых сторонних компонентах, см. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

| Путь | Назначение |
|---|---|
| `backend/` | FastAPI, генерация, сохранения, runtime-каталоги, WebP и эмбиент |

| `assets/backgrounds/` | Исходные фоны и параметры генерации |
| `assets/characters/` | 235 спрайтов, оригиналы, разметка лиц и галереи |
| `tools/` | Подготовка графики и проверка публикации |
| `StoryEngine_Anima_Characters_Colab.ipynb` | Необязательная генерация новых персонажей в Colab |
| `docs/ENGINE.md` | Подробности поведения и архитектуры |

Исходные изображения оставлены для воспроизводимости; пересоздавать их для
запуска не нужно. [Порядок публикации](PUBLISHING.md),
[решения проекта](DECISIONS.md), [правила работы с кодом](AGENTS.md).
